# 🌷 Tulip PIE 🥧

A silly little town. Walk around with the arrow keys or WASD, click the sky for fireworks, and bump into (or click) a building to play its game:

| Building | Game |
|---|---|
| 🐴 Hoofbeat Stables | Grand Pony Derby: jump hurdles, dodge mud, grab carrots and stars, beat your best time |
| ⛸️ Frosty Loop Rink | Snowflake Catch: catch ❄️ and ⭐, dodge 🐧 |
| 🍋 Lulu's Lemonade | Lemonade Rush: make the right cup, fast |
| 🖍️ Museum of Crayons | Art Studio: crayon, marker, rainbow, glitter, fill, stickers, mirror mode, undo/redo, daily themes and a curator who rates your art |
| 🎩 Hats Hats Hats | Hat Rush: give customers the hat they want |
| 🛋️ Couch-Making Academy | Cushion Stacker: build the tallest couch |
| 🧦 Lost Sock Office | Memory match: reunite the pairs |
| 💅 Glitter Claws Nails | Polish Panic: paint nails to match each customer |
| 🪙 The Penny House | Penny Press: stamp pennies with perfect timing. Every penny = 1 casino coin |
| ⛰️ Mount Wobblemore | Trike Climb: a Getting-Over-It-style climb… on a tricycle (A/D pedal, Space jumps, drag to fling) |
| ❌⭕ Tic-Tac-Toe Club | Tic-Tac-Toe vs. Professor Hoot 🦉 (Easy or Hard) |
| 🦆 Duck Pond | Feed the Ducks before Gerald the goose steals the bread |
| 🧟 Chill Zombie Manor | Explore a house of chill zombies. Crack the lock on Granny's door, avoid Granny Grumbles 👵, find the key 🔑 and the bomb 💣 |
| 🐼 Panda Gym | Bamboo Workout: a rhythm game with Coach Bao Bao |
| 🎹 Tiny Piano | Out on the grass. Click it and it zooms up big: play, record (optionally with your voice 🎤), save and delete songs |
| 🦷 Dentist | Tooth Trouble: pull junk out of teeth, drill cavities, scrub plaque |
| 🏈 Teacup Stadium | Tea-Down Toss: slingshot a football into a giant teacup |
| 🏹 Fancy Archery | Perfume Panic: stick arrows in a spinning target without draining the leaky perfume bottle |
| 🥄 Spoon Orchard | Spoon Harvest: pick ripe spoons, grab golden ones, avoid the forks |
| 🏦 Secret bank | Find the hidden 🧱 in Penny Press, bring Granny's 💣, blow the vault, get ∞ casino coins |
| 🎰 Lucky Clover Casino | Locked until you find the key. Spend coins (from pennies you stamp at The Penny House) on skin slots, then pick a skin in the wardrobe |

Everything lives in a single `index.html`. GitHub Pages serves it straight from the `main` branch.
